DÉPLOIEMENT LWS — Queen of Excellence (MySQL + KKiaPay)
=========================================================

Ce zip contient le site DÉJÀ COMPILÉ (.next). Pas de build sur le serveur.

────────────────────────────────────────────────
1. BASE DE DONNÉES (cPanel → phpMyAdmin)
────────────────────────────────────────────────
   Importer dans l'ordre :
   - database/schema.mysql.sql
   - database/seed.mysql.sql        (admin uniquement, contenus vides)
   - database/migrations/add-event-categories.sql  (si pas déjà dans schema)

   Admin initial :
   Email        : admin@queenofexcellence.com
   Mot de passe : admin123
   → Changez le mot de passe après la 1ère connexion.

   Tout le contenu (slides, événements, candidates, partenaires, FAQ…)
   s'ajoute depuis : https://queenofexcellence.com/admin

────────────────────────────────────────────────
2. UPLOAD DES FICHIERS
────────────────────────────────────────────────
   Extraire TOUT ce zip dans :
   ~/queenofex
   (PAS dans public_html — Passenger pointe vers ~/queenofex)

   REDÉPLOIEMENT (site déjà en ligne) :
   1. cPanel → Node.js → ARRÊTER l'app
   2. Sauvegarder public/uploads/ (images admin) si besoin
   3. Extraire le zip PAR-DESSUS l'ancien dossier :
      cd ~ && unzip -o queenofex-deploy.zip -d ~/queenofex
      (ne supprime PAS public/uploads si déjà présent)
   4. bash ~/queenofex/install.sh
   5. Node.js → DÉMARRER (attendre 2 min après ARRÊTER)
   6. Fastest Cache → Purger le cache
   7. NE PAS patcher manuellement les fichiers .next/server/chunks/

   Test votes après deploy :
   https://queenofexcellence.com/api/public/candidates?eventSlug=gala-ifsio
   → voteCount et number doivent être des NOMBRES (0, 1, 2…), pas true/false

────────────────────────────────────────────────
3. PASSENGER (.htaccess)
────────────────────────────────────────────────
   IMPORTANT — ne copiez PAS un .htaccess avec un chemin Node en dur.

   Méthode recommandée :
   1. cPanel → Setup Node.js App
   2. Créer / modifier l'app :
      - Racine     : queenofexcellence
      - URL        : queenofexcellence.com
      - Fichier    : server.js
      - Node.js    : 18 ou 20 (selon disponible)
   3. Enregistrer → cPanel génère automatiquement le bon .htaccess
      dans public_html avec le chemin Node correct.

   Si vous devez copier manuellement, récupérez d'abord le chemin Node
   affiché en haut de Setup Node.js App (commande "source .../activate")
   ou dans le terminal :
   find ~/nodevenv ~/nodeenv -name node -type f 2>/dev/null

────────────────────────────────────────────────

────────────────────────────────────────────────

────────────────────────────────────────────────
